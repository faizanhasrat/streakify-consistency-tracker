# ⚡ Streakify: Daily Study & Consistency Engine

A local-first productivity dashboard designed to track daily goals, study sessions, and consistency streaks with zero backend required.

## 🛠️ Built With
* HTML5 & Tailwind CSS (CDN)
* Vanilla JavaScript (ES6+)
* Browser `LocalStorage` for zero-setup persistence

## 🚀 How to Run Locally
1. Download or clone this repository.
2. Open `consistency_tracker.html` directly in any web browser, OR run `node server.js` to host it locally on `http://localhost:3000`.
